**BramLabs** is an independent product studio. We ship focused software and the brand assets that belong to it.

We started with browser extensions because it's an honest format: one permission scope, one job, one user benefit. No accounts, no subscriptions, no telemetry unless the feature literally needs it. You install, it works, you stay in control.

## What we build

1. **Apps** — original titles on the Amazon Appstore. Same local-first philosophy as our extensions.
2. **Extensions** — focused Chrome utilities. [StoryPeek](/extensions/story-peek) for anonymous Instagram story viewing and media downloads. [SnapElite](/extensions/snap-elite) for full-page and viewport screen capture. [SonicShield](/extensions/sonic-shield) for per-site audio normalization.
3. **Web** — production sites with real content systems. [WorkflowAI.site](https://www.workflowai.site) is the flagship: 950+ workflow blueprints, MCP configs, and design packs for builders.
4. **Art & merch** — print-ready designs for our own products. 300 DPI, original geometry and wordmarks, USPTO-checked before publish. [See the portfolio →](/merch)

## How we work

Every product ships with its own support page, privacy policy, and terms. We don't reuse a generic boilerplate across unrelated tools — each product is documented for the actual permissions it requests.

For merch, the rule is simple: if we don't own the IP, we don't sell it. That means no fan art, no sports logos, no character derivatives. Just original marks for products built in this studio.

This site ([bramlabs.co](https://bramlabs.co)) is the studio hub and developer reference for both store applications and merch reviews.
