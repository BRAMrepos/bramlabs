## Professional Screen Capture

SnapElite is a modern, lightweight screen capture tool built to solve page snapshotting tasks. It provides useful features like region capture, custom annotations, blur redactions, and WebP exports for free.

## How it works

All screen captures, image stitching, and editor operations are executed directly inside your browser. This enables fast, offline execution:
- **Scrolling stitching**: Automatically scrolls down vertical pages to stitch together full snapshots.
- **Crop capture**: Allows you to hover over elements or drag selection boxes to crop specific sections.
- **Canvas Editor**: Instantly annotate screenshots with shapes, lines, numbers, and text before downloading.

## Supported Formats

You can download captures in four main formats:
1. **PNG**: Lossless quality, best for diagrams and mockups.
2. **JPG**: Compressed file size, ideal for photos and web pages.
3. **WebP**: Modern image format featuring excellent quality/compression ratios.
4. **PDF**: Document format, great for sharing reports or printing pages.
